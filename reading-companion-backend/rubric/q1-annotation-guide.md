# Q1 人工标注说明

配合 `q1-v3.4.md` 使用。rubric 定标准，每一项可以单独判；这份说明只管一件事：**一个人一次判完一条批注的所有项时，按什么顺序走**。每一项怎么判，以 rubric 对应的一节为准。

顺序有讲究：有的项要在"第一次读"时判，读过几遍之后就判不了了。

## Note

**第一步：第一印象**
读一遍，凭直觉记下：过，还是不过。不查 rubric。
用途：和后面按 rubric 判出的结论对比，看 rubric 有没有漏掉你在意的东西。

**第二步：读着费劲**（rubric 2.3）
就用刚才那一遍，马上用一句大白话说出它讲了什么。说不出或说偏了，再试着改写，按 2.3 判。
必须在重读之前判完。

**第三步：N1 增量**（rubric 2.2）
现在可以重读，读懂后复述，按 2.2 判过或不过。
- 用到了锚点之后的内容：先分清是"紧接着几段要讲的"（N1 不过），还是"挂早了"（挪过去再判，记下锚点问题）
- 判过且走的是"其他写法"：写一句这是什么写法、增量在哪
- 不过：多选失败类型

**第四步：有剧透**（rubric 2.4）

**第五步：有错误信息**（rubric 2.5）
拿不准就勾"待核实"。

**第六步：出结论**
按 rubric 2.1 的合成规则：N1 过，并且第二、四、五步都没勾，才算过。

**第七步：标签**（rubric 2.6）
只有第六步判"过"的才标。第三步记下的锚点问题在这里标上。

**随时**：拿不准、rubric 未覆盖、星（rubric 1.4）。
