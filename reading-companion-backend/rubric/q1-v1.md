## 适用范围
- 场景：共读型。读者顺序阅读，在某处看到另一位读者留下的想法。
- 标准观察者：第一次读这本书、读过同类书、受过高等教育的普通读者。不是重读者，也不是专家。
- 判断视角：只看原文 + 这条批注，也就是读者实际看到的东西。不看 trace、不看组别。判完"不过"之后，再去 trace 里找第一个出错的环节。
- 判断单位：每条批注单独判。Highlight 和 Note 分开判、分开算通过率。Highlight 只看选中的文字；带正文的批注一律按 Note 判。
- 绝对标准：只问"这条够不够好"，不跟同单元或其他组的批注比较。同单元里还有别的好位置没标，记作漏标，不影响这一条。

## 判定规则
- 每个**判定条目**都要明确判"过"或"不过"。即使已经有一条不过，其余条目也要判完。
- 所有判定条目都过，才算 **过**。理由选填。
- 觉得该判不过，但找不到对应的条目：标 **rubric 未覆盖**，写一句原因。这条批注算不过。
- **标签**只记录问题，不导致不过（用来指导改 prompt）。
- **星**：在"过"之上的范例级批注，可以直接拿来当 few-shot 或给别人演示"好的批注长这样"。星要少给。

例子格式：批注正文 + 判定理由（整理过，不是标注时的原话），末尾附 ID（A1 / B = DIAG-001 的组别）。只放模型生成的批注和理由，不放书的原文。每类只放一个代表例子；同类的其他条目只列 ID，作为备用。

## Note

### N1 增量（判定，核心）
**过**：标准观察者读完这段，自己得不到这条 Note 给出的东西。增量的来源：
- **外部知识**：给出概念或理论的名字、读懂这句必需的背景知识、其他作品或历史上的对照、联系现实
- **回应作者**：作者抛出了问题，Note 试着回答
- **有分量的反驳或修正**：指出作者或人物说过头、说错的地方，并且有论据：给出事实、知识或推理，不只是声明一个观点
- **前后文关联**：把当前段和前文联系起来，读出第一次读时多半串不起来的东西
- **深层解读**：纯文字层面的解读也可以，前提是第一次读时多半品不出来；或者读者隐约感到、但说不清楚，Note 把它说透了

**不过**：
- 复述原文，或者换个说法讲一遍
- 讲显而易见的东西，读者读到这里自己就能想到
- 用抽象术语、论文腔包装复述或常识：看起来在说什么，抽掉术语什么也没说
- 提到一个理论或概念，却说不清它是什么、和这里有什么关系，读者带不走任何东西
- 补的知识分量不够：读者望文就能猜个八九不离十，或者知道了也不改变对这句的理解
- 只补一个专名，其余内容和原文（含紧接着的下一句）重复
- 概括后文
- 作者抛出了问题，Note 只是复述问题或说"这值得思考"
- 提出异议，但只是声明观点，没有事实、知识或推理支撑
- 在不重要的地方较真，或者只在文字上挑毛病
- 外部知识和原书注释重复，没有超出注释

**边界**：
- 两条都在质疑作者，区别在于有没有论据、有没有带来新东西。
- 异议没有论据 → N1 不过。异议所依据的事实本身错了 → N2 不过。
- "深层解读"和"阅读理解"的分界：标准观察者第一次读到这里，会不会自然地、清楚地想到这一层？会 → 不过。只是隐约感到、Note 说透了 → 过。
- 原书已有注释的地方可以再写 Note，但必须超出注释，比如把背景知识和情节放在一起阐释。
- 外部知识有没有分量：问"不知道这个，读这句会不会读不懂或读浅"。会 → 有分量（初领圣体、主显节、民事婚礼）；不会 → 分量不够（中学会考）。
- 一条 Note 只要有一处真增量就过；附带的多余解读记"冗余"标签，不判不过。

### N2 准确（判定）
**过**：
- 对本书内容的描述忠实，没有歪曲原文或前文
- 外部事实正确：人名、年代、事件、概念的含义没有说错
- 引用的理论或概念用对了，不是张冠李戴

**不过**：事实错误；歪曲原文；编造不存在的事实、出处或理论。

**边界**：
- 拿不准某个外部事实是否正确时，标"待核实"，先判过，统计时单列。不要因为听起来有学问就放过。
- 解读有没有说服力、异议有没有论据，都不归这条（归 N1）。只有把书里的内容或外部事实说错了，才算 N2 不过。

**例子**：目前两批标注里还没有因为事实错误判不过的批注。这一条先按定义判，出现真实例子后补上。

### N3 不剧透（判定）
**过**：只用到当前位置及之前的内容，或者书外的常识。
**不过**：透露后文情节或后文才展开的论点。出现一次就算。

### N4 锚点（判定）
**过**：
- Note 说的东西就是从这个锚点生出来的，挪到别的章节就不成立了
- 锚点范围完整，不是半句

**不过**：
- 挂在一个不重要的句子上，看起来是先想好要说什么，再随便挑一句挂上去（第一批包法利里约 15 条）
- 内容和锚点关系不大：引了一个放哪都能说的理论或感想
- 只标了半句；或者同一处被拆成一条 Highlight 和一条 Note

### 标签（不导致不过）
- **老师口吻**：教读者怎么读，如"读这句话时可以留意……"。有真实增量就照样过（见 N1"把读者隐约感到的说透"那条）。没有增量的，按 N1 判不过，例如：
  > ……后文读到爱玛时，可留意这种"率真和果决"是否与她实际处境相合。

  理由：AI 没有自己在读书，而是在教用户怎么读书。`A1 u000011-replay-m001`
- **冗余**：有增量，但附带了多余的主观解读。例如：
  > "初领圣体"指天主教儿童第一次领受圣体的仪式，通常是重要的成长礼仪。白裙被留到婚礼时再次穿用并修改，暗示乡村家庭会让衣物跨越不同的礼仪场合反复使用……

  理由：引入了外部知识，帮助读者理解，但后半句解读有些多余。判过。`A1 u000022-replay-m002`
- **太简练**：意思没展开，读者可能意会不到（见 N1"超出原书注释"那条）。

## Highlight

### H1 值得停下来（判定）
**过**：标准观察者读到这里，会想停下来再看一遍的文字。
- 小说：极美的文字（意象、风景、精妙的比喻）、对人性的洞察
- 非虚构：核心论点、精辟的句子、反直觉的观点、关键概念的定义

**不过**：推进情节的普通句子、过渡句、平常的事实陈述。

### H2 范围完整（判定）
**过**：选中的部分自己就是一个完整的意思。
**不过**：截断半句；一个意思被切开，单看选中部分读不懂。

**边界**：选中部分自己完整，但前后还有同样值得标的句子 → H2 过，另记漏标。只有选中部分本身残缺才判不过。

### H3 脱离上下文仍有价值（判定）
检验方法：假设读者以后只翻看自己的高亮列表，只知道这是哪本书，单看这段文字。

**过**：能看懂在说什么，而且单独拿出来仍有价值。比如一句格言、一个完整的论点、一段优美的景物描写、一句对人性的洞察。

**不过**：
- 离开上下文看不懂：指代前文的"这""此""他们"，只在本书里定义过的说法，省略了主语或前提
- 看得懂，但只在这个情节或这段论证里有意义：推进情节的转折、论证中间的一步、只对本段起承接作用的句子

**边界**：
- 指代主角的"她""他"可以接受，知道书名就知道是谁。
- H2 管的是"切得对不对"，H3 管的是"选得对不对"：一句完整的句子可以 H2 过、H3 不过。
